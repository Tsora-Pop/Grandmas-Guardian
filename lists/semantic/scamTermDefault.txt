# The filter itself also catches common disguises of every phrase above:
#   - spaced or dotted letters:   g i f t  c a r d s,  G.I.F.T
#   - joined or hyphenated words: giftcards, gift-cards
#   - numbers/symbols for letters: g1ft c4rds, B1tc0in, $end
#   - look-alike letters from other alphabets (Cyrillic "о", Greek "ο")
#   - fancy Unicode letters (bold/fullwidth), accents, invisible characters
#   - a phrase split across formatting tags or padded with hidden letters
# So only genuinely different wording needs its own line below.
# ===========================================================================
