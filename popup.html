Set up Grandma's Guardian

A few quick steps. You can change everything later.

    Who can they call for help?

    Your name and phone number appear on blocked pages, so if something is blocked they call you, not a stranger on the screen.

    Choose the protections

    All four are recommended. Lists download automatically and update once a day.

    Add the websites they use

    Only allowed websites will open. Add the sites this computer already visits most, then any others they need (their bank, church, pharmacy…).

    Protect private (Incognito) windows

    ✅ Private windows are protected.

    Chrome turns extensions off in private windows unless you allow it. Scammers know this.

    1. Click Open extension settings.
    2. Turn on Allow in Incognito.
    3. Come back here and click Check again.

    All set 🎉

    • Pin the shield to the toolbar: click the puzzle piece 🧩 next to the address bar, then the pin.
    • Blocked pages offer an Ask to allow button. Requests show up here for you to approve.
    • For computers you manage, see the deployment notes in the README to force-install the extension and lock private windows by policy.

    Grandma's Guardian

    No real company will ever ask you to change these settings over the phone. If someone does, hang up and call your helper.

    Requests to allow

    Only allow these websites

    Every other website is blocked.

    Always block these websites

    Blocked even if they are on the allowed list (remote-control tools, abused hosting).

    Requests to allow a file type

    Allowing a file type lets every file of that kind download from any allowed website.

    Only allow these file types

    Other downloads are stopped. Types are written like application/pdf (reference).

    Hide text with scam words

    Matching paragraphs are hidden behind a notice with a Show anyway button.
